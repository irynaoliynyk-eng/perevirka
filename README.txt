Перевірка графіки – StandPoint
Статична сторінка для перевірки макетів. Серверної частини немає: файли користувача
обробляються лише в браузері й нікуди не надсилаються.

СКЛАД
  index.html                          – сторінка (HTML, CSS і JS всередині, вбудовані зображення)
  informatsiia-dlia-eksponenta.pdf    – документ, кнопка «для експонента»
  informatsiia-dlia-menedzhera.pdf    – документ, кнопка «для менеджера»
  katalog-obladnannia.pdf             – каталог обладнання, кнопка «обладнання»
  lib/pdf.min.js, lib/pdf.worker.min.js – pdf.js 3.11.174 (превʼю PDF/AI)
  lib/UTIF.js                         – UTIF 3.1.0 (превʼю TIFF)
  lib/pako.min.js                     – pako 2.1.0 (розпакування для UTIF)

РОЗМІЩЕННЯ
1. Скопіювати папку perevirka цілою в корінь сайту, щоб сторінка відкривалась як
   https://<домен>/perevirka/
   Усі шляхи відносні – можна розмістити в будь-якій іншій папці або на піддомені,
   головне не розділяти файли (index.html, PDF і lib/ мають лежати як в архіві).
2. Нічого збирати чи встановлювати не потрібно. Підійде будь-який вебсервер
   (Apache, Nginx, хостинг з файловим менеджером).
3. Якщо сайт на WordPress чи іншій CMS: стандартні правила перенаправлення
   не чіпають реальні папки, тож /perevirka/ відкриється напряму.
   Якщо ні – додайте виняток для цієї папки.

ЩО ВРАХУВАТИ
- HTTPS: бажано (кнопка «Скопіювати» в браузерах працює лише на HTTPS).
- Content-Security-Policy (якщо на сайті задано заголовок CSP), сторінці потрібні:
    script-src 'self' 'unsafe-inline'
    style-src  'self' 'unsafe-inline' https://fonts.googleapis.com
    font-src   'self' https://fonts.gstatic.com
    img-src    'self' data: blob:
    worker-src 'self' blob:
  Без CSP нічого налаштовувати не треба.
- Зовнішні запити: лише шрифти Google Fonts. Без них сторінка працює, але
  шрифти будуть системні.
- Кешування: після оновлення index.html варто скинути кеш CDN/сервера, якщо він є.

ОНОВЛЕННЯ
- Сторінка: замінити index.html.
- Документи: замінити PDF файлом з тією самою назвою.
- Папку lib/ оновлювати не потрібно.
